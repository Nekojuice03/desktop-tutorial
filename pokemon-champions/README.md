# Champions 對戰分析台

一個單檔、離線可用的 **Pokémon Champions 組隊 / 環境 / 努力值分析工具**。
直接用瀏覽器開啟 [`index.html`](./index.html) 即可，無需安裝或連網。

## 功能

| 分頁 | 回答的問題 |
|------|------------|
| **主流隊伍 Metagame** | 目前主流的隊伍骨架有哪些？各自的遊玩計畫、核心威脅、天敵。 |
| **應對搭配 Counters** | 面對某隻威脅（或整支主流隊伍），該帶什麼去打？系統從圖鑑找出**同時抵抗其主打屬性、又能打中其弱點**的應對寶可夢並比較速度。 |
| **速度超車 Speed Tiers** | 要點多少**速度努力值 / 性格**才能超車目標？可套用命運頭巾（×1.5）與順風（×2）。 |
| **存活配點 Survival EVs** | 要點多少 **HP / 防禦努力值**才不會被某招一擊帶走？用第九世代傷害公式求「保證擋下最大亂數」的最省配點。 |

右上角可切換 **Lv.50 / Lv.100** 與 **亮 / 暗色**佈景。

## 計算引擎

數值採現行**第九世代標準公式**，級距精確：

- 實數值：`HP = ⌊(2·種族+IV+⌊EV/4⌋)·L/100⌋ + L + 10`；其他項含性格 ×0.9 / ×1.1。
- 傷害：標準 base damage 公式 + 85–100 亂數、STAB、屬性相剋、天候、講究類（×1.5）/ 生命寶珠（×1.3）、齊射（×0.75）。
- 求解器：以窮舉在 0–252（每 4 點）內找**最小努力值**達成「超車」或「保證存活」。

引擎已用已知數值驗證（如 Lv50 熾焰咆哮虎 252HP=202、振翼發滿速+性格=205）。

## 更新資料（重要）

`POKEDEX`、`MOVES` 為第九世代真實數值；**`META_TEAMS` 為策展資料**——
Pokémon Champions 的正式競技環境數據尚未公開，主流隊伍係以現代雙打 / VGC 常見骨架為藍本，
方便你依實際天梯調整。

所有資料都內嵌在 `index.html` 的 `<script>` 區塊，直接編輯對應物件即可，計算引擎不受影響：

```js
const META_TEAMS = [ { id, name, style, usage, core:[...], plan, keyThreats:[...], counters:[...], note }, ... ];
const POKEDEX    = { key: { name, zh, types:[...], base:[HP,Atk,Def,SpA,SpD,Spe], role, tier } };
const MOVES      = { key: { zh, type, cat:'Physical'|'Special', power } };
```

新增一隻寶可夢只要在 `POKEDEX` 加一筆，其他分頁的下拉選單會自動帶入。
